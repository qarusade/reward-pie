# CLAUDE.md — Reward Pie

Ты помогаешь Эмину делать его личный дашборд задач с наградами. Это PWA: один код для телефона и браузера на компьютере. Общается Эмин по-русски, отвечай по-русски.

## Уровень подтверждения

**Делай сам, спрашивай только на развилках.** Это выбор Эмина (2026-11-05): реализуй фичи сразу и останавливайся только на решениях про продукт или дизайн, которые не вытекают из описания ниже. Если просьба противоречит решению из списка ниже, сначала уточни.

После изменений:
1. `npm run typecheck` и `npm test` — должны проходить.
2. Проверь экран в браузере (`npm run dev`), а не только тесты.
3. Короткий отчёт: что поменялось и что не проверено.

Коммитить и пушить — только когда попросят. **Каждый push в `main` сразу выкладывает приложение на прод**, поэтому перед push тесты и сборка должны проходить локально.

## Продуктовые решения (подтверждены Эмином 2026-11-05)

- **Платформа:** PWA на React + Vite + TypeScript. Нативных приложений нет.
- **Данные:** только локально на устройстве, в IndexedDB. Синхронизацию телефона и компьютера сделаем позже, и подключать её (например Supabase) нужно в одном месте — `src/store/storage.ts`. Остальной код не должен знать, где лежат данные.
- **Награды по категориям, а не «награда дня».** У каждой категории своя картинка-награда. За день она режется на столько кусков, сколько у категории задач; закрыл задачу — открылся кусок. Все задачи категории за день закрыты — награда открыта.
- **Категории** пользователь создаёт сам, сколько угодно. У категории есть название, цвет и награда: пресет-картинка или своё фото, плюс название награды.
- **Задачи привязаны к дате.** Каждый день новые; прошлые дни видны в «Истории». Задачи можно планировать и на будущие дни через полоску недели.
- **Стиль:** вариант «A · Поп-пицца» из макета — жёлтый фон `#FFE14D`, толстые чёрные обводки, жёсткие тени, шрифты Unbounded (заголовки) и Onest (текст). Макет: https://claude.ai/artifact/5LiGJjHDB9g5kEBKntASds. Варианты B и C на холсте отклонены.
- **Задачи добавляются полем внизу карточки каждой категории.** Это отступление от исходного «одно поле внизу экрана», Эмину о нём сказано. Если попросит общее поле — вернуть.
- **Приоритет задач — перетаскиванием** (просьба Эмина 2026-11-05): за ручку ⠿ слева, вверх-вниз внутри своей категории за свой день. Новая задача встаёт в низ списка. Закрытые задачи сами вниз не уезжают. Перенос задачи в другую категорию или на другой день не сделан, о нём не просили.

## Устройство кода

```
src/
  types.ts            Category, Task, Reward (kind: pizza|game|movie|sweet|photo)
  palette.ts          цвета категорий и пресеты наград
  lib/dates.ts        ключи дат 'YYYY-MM-DD' в ЛОКАЛЬНОМ времени, неделя с понедельника, русские подписи
  lib/stats.ts        прогресс категории/дня, геометрия пирога, счётчики наград — чистые функции, покрыты тестами
  lib/order.ts        порядок задач (поле order), перестановка, нумерация старых данных — тоже чистые и с тестами
  lib/image.ts        своё фото → квадрат 512px JPEG data URL (хранится внутри категории)
  lib/id.ts           newId()
  store/storage.ts    адаптер хранилища: IndexedDB → localStorage → память
  store/store.ts      zustand + persist; все изменения данных только через экшены стора
  components/         RewardPie (картинка + «пелена» + разрезы), RewardArt (SVG-пресеты), CategoryCard, TaskList (перетаскивание на @dnd-kit), CategorySheet (создание/правка в <dialog>), WeekStrip, …
  screens/            TodayScreen, HistoryScreen, RewardsScreen
  styles.css          все стили; токены в :root
```

- Удаление категории, у которой есть задачи, — это архивирование (`archived: true`): она пропадает из новых дней, но остаётся в истории. Категория без задач удаляется насовсем.
- Анимация открытия куска работает через `@property --deg` в `styles.css`. Где `@property` не поддерживается, кусок просто появляется без анимации.

## Подводные камни

- `crypto.randomUUID` недоступен в небезопасном контексте, то есть на телефоне по `http://192.168…`. Поэтому id создаём только через `newId()` из `lib/id.ts`.
- Service worker и установка на главный экран работают только на https или `localhost`. По LAN-IP приложение работает, но без офлайна.
- Данные живут только в браузере. Если очистить данные сайта, пропадёт всё. На старте зовём `navigator.storage.persist()`, чтобы браузер не вычищал их сам. Пока нет синхронизации, это главный риск: о нём стоит помнить при любых правках хранилища.
- Не ломай формат сохранённых данных без миграции: в `persist` стоит `version` (сейчас 2), переходы — в `migrate()` в `store/store.ts`, на каждый переход есть тест. При смене схемы поднимай версию и добавляй шаг, иначе у Эмина пропадёт история. v1 → v2: у задач появился `order`.
- Ручка перетаскивания держит `touch-action: none`: без этого на телефоне палец скроллит страницу. Тащить можно только за ручку, остальная строка скроллится как обычно.
- Проверка перетаскивания в браузере Claude: `left_click_drag` не годится, dnd-kit его не видит (ему нужно несколько движений после нажатия). Шли `PointerEvent` (`pointerdown` на ручке, серия `pointermove`, `pointerup`) из JS. Клавиатура: фокус на ручке, `space`, `ArrowDown`, `space` (имя клавиши `Down` не срабатывает).
- Превью дев-сервера в Claude запускается с `--host 127.0.0.1` (`.claude/launch.json`): по умолчанию Vite слушает только `::1`, а браузер Claude туда не достучивается.
