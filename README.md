# Reward Pie

Личный дашборд задач на день, который работает и на телефоне, и в браузере на компьютере. Задачи разбиты по категориям. У каждой категории своя награда-картинка: пицца, поиграть в комп, кино и так далее. Она открывается кусочками, пока закрываешь задачи этой категории.

## Что это делает

- Каждый день вписываешь задачи в нужные категории. Категории создаёшь сам, сколько угодно.
- Картинка-награда категории делится на столько кусков, сколько в ней задач за день. Закрыл одну задачу из шести — открылась 1/6 картинки.
- Сверху показан итог дня: сколько задач закрыто, процент и сколько наград открыто. Под ним неделя с кольцами по дням.
- «История» — прошлые дни с процентами и заработанными наградами. «Награды» — настройка категорий и их картинок, в том числе своё фото.

## Где открыть

**https://qarusade.github.io/reward-pie/**

Как поставить на телефон:
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение» или «Добавить на главный экран».

После установки приложение работает и без интернета. Данные хранятся на каждом устройстве отдельно: телефон и компьютер пока не синхронизируются.

Выкладка автоматическая: каждый push в `main` собирается и публикуется через GitHub Actions (`.github/workflows/deploy.yml`).

## Быстрый старт (на новой машине / в другом интерфейсе Claude Code)

1. Открой Claude Code в этой папке: `CLAUDE.md` подхватится сам.
2. Нужен Node.js 20+ (проверено на 24). Установи зависимости: `npm install`.
3. Запусти: `npm run dev`, затем открой http://localhost:5173.
4. На телефоне: `npm run dev -- --host` и открой адрес из консоли (`http://192.168.x.x:5173`) в той же Wi-Fi сети. Чтобы поставить приложение на главный экран и пользоваться им офлайн, нужен https: локально это работает только на `localhost`, полноценно — после деплоя.

Команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер |
| `npm run build` | проверка типов + прод-сборка в `dist/` (с service worker) |
| `npm run preview` | посмотреть прод-сборку локально |
| `npm test` | юнит-тесты (Vitest) |
| `npm run typecheck` | только проверка типов |
| `npm run icons` | перегенерировать PWA-иконки из `public/favicon.svg` |

## Файлы в этой папке

- **CLAUDE.md** — правила работы Claude в проекте, принятые продуктовые решения и подводные камни.
- **src/** — код приложения (устройство описано в `CLAUDE.md`).
- **public/** — иконки PWA (`favicon.svg` — исходник, остальное генерируется).
